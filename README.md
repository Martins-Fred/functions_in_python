# Functions in Python

A beginner-friendly collection of Python examples covering functions, variable scope, return values, and list operations.

## Requirements

- Python 3
- A terminal or command prompt

No external packages are required.

## Getting Started

Clone the repository and move into the project folder:

```bash
git clone https://github.com/Martins-Fred/functions_in_python.git
cd functions_in_python
```

Run an example with Python:

```bash
python main.py
```

## Learning Notes

- A function groups reusable code and should usually perform one clearly defined task.
- Use `return` when a function needs to send a value back to the caller.
- Variables defined outside functions are global variables.
- Variables defined inside functions are local variables.
- List indexes start at `0`; negative indexes count backward from the end.
